# Docs Plans

This folder holds active design notes and implementation plans that still matter to the project.

## Conventions

- Use stable names without date prefixes for durable proposals.
- Keep one file per topic.
- Move finished plans into `docs/internal/` or merge them into the main docs once they become product guidance.
