# Hera Agent v2.0.0 🎉

The first production-ready release of Hera Agent - an OpenCode plugin that creates agents with memory, skills, team collaboration, and self-evolution capabilities.

## 🚀 Highlights

- **Zero-Config Setup**: Auto-creates configuration on first load
- **10 Agent Templates**: General, Coder, Reviewer, Researcher, Coordinator, Architect, Debugger, Tester, Documenter, Optimizer
- **Team Collaboration**: Multi-agent coordination with parallel/sequential/adaptive modes
- **Self-Evolution**: Agents improve through reflection and directive appending
- **Persistent Memory**: Knowledge retention across sessions
- **25+ Management Tools**: Complete agent/skill/team lifecycle management

## 📦 Installation

```bash
opencode plugin hera-agent --global -f
```
